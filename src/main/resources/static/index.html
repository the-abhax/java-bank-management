Banking API

The Spring Boot banking service is ready on port 8080. Use the REST endpoints below from your frontend or an API client.

MethodEndpointPurpose
POST/api/auth/registerRegister a user
POST/api/auth/loginLog in
POST/api/accountsOpen an account
GET/api/accounts?email=...Find an account
POST/api/accounts/{id}/creditCredit money
POST/api/accounts/{id}/debitDebit money
POST/api/accounts/{id}/transferTransfer money
